ArcheaAge · UI Studio

Design the in-game UI: inspect native windows, move them, create your own widgets, and export everything the ivanpanel addon applies.

  1. Play ArcheAge once until the server-select screen (exports the native inventory).
  2. Import tree.json → pick Documents\ArcheAge\ivanpanel_tree.json
  3. Navigate the tree, drag elements, create new widgets.
  4. Export → writes tools\ui\overrides.lua
  5. Run tools\ui\push-ui.ps1 → reopen the game.
