ArcheaAge · UI Studio

Design the in-game UI: inspect native windows, move them, create your own widgets, export everything.

  1. Play once until server-select (generates the native inventory).
  2. Import tree.json → Documents\ArcheAge\ivanpanel_tree.json
  3. Navigate / drag / create widgets.
  4. Export overrides.lua
  5. Run tools\ui\push-ui.ps1, reopen the game.
